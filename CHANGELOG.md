# Changelog

All notable changes to this project are documented below. Genesis reached general availability with the v1.0.1 Perfection Build, completing the thirteen research and engineering phases.

| 2 | Evaluation loop | Autonomous evaluator service, benchmark harness, reward models |

## Phase 12.x → Phase 13 Highlights

- ✅ API latency improvements: p95 dropped by 21.4%, reducing tail from 96 ms to 75 ms under soak.
- ✅ Memory stability: worker memory drift held below 5% over 24h adaptive loads.
- ✅ Quality assurance: automated coverage sustained at ~98% across critical paths.
- ✅ Chaos readiness: composite recovery time from orchestrated failures measured ≤ 10 seconds.

## Genesis v1.0.1 – Perfection Build (Stable Release)

The 1.0.1 release locks the unified architecture, publishes the regeneration toolchain, and certifies the benchmark suite for long-term support deployments.
